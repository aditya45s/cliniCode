# Security Policy

CareKare is a demonstration project and is not intended for production healthcare, identity verification, or emergency use.

## Reporting a vulnerability

Do not include secrets, credentials, private keys, uploaded documents, or personal health information in public issues. Contact the repository owner privately with a concise description, reproduction steps, and impact.

## Data handling

Use synthetic demo data only. Keep `.env` files, MongoDB dumps, local uploads, and service credentials outside Git.
